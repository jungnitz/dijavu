dijavu is an opinionated dependency injection framework with a strict separation between application initialization and runtime.
Most dependency injection frameworks operate on a single object graph.
dijavu instead treats initialization and runtime as separate phases with different requirements.

Initialization focuses on mutation, configuration, and construction.
Runtime focuses on stable, immutable access to application state.
A build process transforms the initialization state into the runtime state in three steps:

1. **Declare**: every injectable declares what it references and provides, which discovers all injectables and their bindings.
2. **Prepare**: injectables are prepared in dependency order, and can configure the injectables they depend on.
3. **Assemble**: the final injectables are created, and references between them are enabled once all of them exist.

Most types therefore exist in multiple forms: a state for each build step and a runtime representation.
These representations are often structurally similar (hence the name), but serve different purposes.

### Features and Caveats

- Fully typed dependency injection, with support for generic types and trait objects
- Derive macros for common injection patterns, including hooks to customize each build step
- Support for cyclic references between injectable types
- Being primarily targeted at backend services, most functions and hooks provided by the framework are `async`

### Example

```rust
use std::collections::HashMap;
use dijavu::{*, fields::{Depend, Value}, state::{Declare, Preparing as PreparingState}};

#[derive(Injectable)]
pub struct Configuration(Value<HashMap<String, String>>);

// `ConfigurationState` is automatically generated by the derive macro and similarly structured to
// `Configuration`. Here, its first field is the mutable `HashMap<String, String>`.
impl ConfigurationState<PreparingState<'_>> {
    pub fn put(&mut self, key: impl Into<String>, value: impl Into<String>) {
        self.0.insert(key.into(), value.into());
    }
}

impl Configuration {
    pub fn get(&self, key: &str) -> Option<&String> {
        self.0.get(key)
    }
}

#[derive(Injectable)]
#[injectable(prepare = Self::configure)]
pub struct MyService {
    // `Depend` ensures that `Configuration` is prepared before `MyService`
    config: Depend<Configuration>,
}

impl MyService {
    async fn configure(
        state: &mut MyServiceState<Declare>,
        mut ctx: PrepareContext<'_, Self>,
    ) -> Result<(), Error> {
        ctx.get(&mut state.config).put("my_service.action", "Hello World!");
        Ok(())
    }

    pub fn action(&self) {
        println!("{}", self.config.get("my_service.action").unwrap());
    }
}

pub async fn start() -> Result<(), Error> {
    let mut builder = Builder::new();
    builder.add::<MyService>();

    let injector: Injector = builder.build().await?;
    injector.get::<MyService>().action();
    // "Hello World!"

    Ok(())
}
#
# futures::executor::block_on(start()).unwrap();
```
